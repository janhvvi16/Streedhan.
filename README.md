# 🌸 STREEDHAN

### A Personal Finance Education and Budgeting App

STREEDHAN is a beginner-friendly personal finance application designed to help women and students understand money management, track expenses, plan budgets, and build savings habits.

## ✨ Features

- 📊 **Budget Planner** – Plan monthly income and expenses.
- 💰 **Savings Goals** – Set savings targets and track progress.
- 📈 **Dashboard** – View spending and budget information through charts.
- 📚 **Money School** – Learn basic financial concepts.
- 🌐 **Multilingual Support** – English, Hindi, and Marathi.
- 🎨 **User-Friendly Interface** – A simple interface with a pastel theme.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- CSS
